プライバシーポリシー

このサイトは、ナム・ドンウォンが自ら運営する個人サイトです。アクセス統計に同意された場合にのみクッキーを使用し、ナム・ドンウォンは訪問された方が誰であるかを特定できる情報を保存しません（第4項）。ご自身でメッセージを残された場合に限り、以下の情報を受け取ります。

1. 受け取る情報と利用目的

  • 芳名録 — メッセージのみを受け取り、芳名録に選んで掲載するために利用します。掲載したメッセージのうち一つを、詩集のページにひとことで掲げることがあります。送信される際、Googleフォームが送信日時を記録し、Googleは自社のプライバシーポリシーに基づき接続情報（IPアドレスなど）を処理することがあります。
  • メール・Instagramのメッセージ — お送りいただいたお名前・メールアドレス・内容は、返信のためにのみ利用します。
  • 芳名録では、メールアドレス・電話番号などの連絡先は受け取りません。

2. 保存期間と削除の時期

  • 芳名録に掲載されなかったメッセージは、受け取った日から30日以内に削除します。
  • 芳名録に掲載されたメッセージは、サイトに残ります。取り下げのお申し出があれば、すぐに取り下げます。
  • メール・Instagramのメッセージでいただいたご連絡は、返信してから6か月以内に削除します。

3. 韓国国外へ移転される情報

  • 移転先：Google LLC（米国など） — 残していただいたメッセージは、ナム・ドンウォンのGoogleフォームに保存され、そのフォームにリンクされたGoogleスプレッドシートにも届きます。
  • 移転される情報：芳名録に残していただいた情報（第1項）。
  • 時期と方法：「送る」ボタンを押したときに、インターネットを通じて。
  • 移転先での利用目的と保存期間：Googleフォームと、リンクされたGoogleスプレッドシートに保管し、掲載されなかったメッセージは受け取った日から30日以内に両方から削除。
  • 拒否の方法：「送る」を押さなければ、送信されません。その場合は、Instagramのメッセージまたはメールでご連絡いただけます。
  • アクセス統計を取るとき（同意された場合のみ） — 移転先：Google LLC（米国・Google Analytics）。移転される情報：クッキー識別子、閲覧したページ・参照元・教保文庫へのリンクのクリック、サイト内検索に入力した言葉と結果の数・詩「拓本」を最後まで読んだかどうか（メールアドレス・電話番号のように見える検索語は送信しません）、ブラウザ・デバイスの情報、ページを開くときにブラウザが送信する接続情報（IPアドレス — 国・都市の推定に使われ、Google AnalyticsはIPアドレスを記録・保存しません）。時期と方法：同意された後、ページを開いたとき、教保文庫へのリンクをクリックしたとき、サイト内検索を使ったとき、「拓本」を最後まで読んだときに、インターネットを通じて。利用目的と保存期間：アクセス統計 — 統計データは14か月後に削除されます。拒否の方法：同意画面で「同意しないで続行する」を押すか、各ページ下部の「クッキー設定」から、いつでも同意を撤回できます。
  • アクセス数を計測するとき — 移転先：Cloudflare, Inc.（米国・Cloudflare Web Analytics）。移転される情報：ページを開くときにブラウザが送る接続情報（IPアドレス・ブラウザ情報）と、閲覧したページのアドレス・参照元・ページの表示速度。時期と方法：ページを開くとき、インターネットで。利用目的：アクセス数の計測 — クッキーや端末の保存領域は使わず、「何人」という合計としてのみ数えます。拒否の方法：ブラウザのトラッキング防止・広告ブロック機能を有効にするか、JavaScriptをオフにすると計測されません。

4. 自動的に収集される情報

  • アクセス統計に同意された場合に限り、Google Analyticsのクッキー（_gaと、_ga_で始まるものの2つ）を、このサイトのドメインで保存します。訪問されたデバイスを区別するために使い、2年後に失効します（Chromeでは400日に短縮されます）。同意を撤回された場合は削除します。閲覧したページ・参照元・教保文庫へのリンクのクリック・サイト内検索の言葉・「拓本」を最後まで読んだこと・ブラウザ・デバイス・国と都市（IPアドレスから推定）・言語・画面サイズを「何人」という人数にまとめて確認し、お名前や連絡先は収集しません（第3項）。
  • このデバイスのブラウザのストレージに、次の10項目を記録しておきます — 初回訪問時の扉のシーンを一度ご覧になったかどうか、「表示」で選ばれた設定（システム・ライト・ダーク）、「動き」を減らす設定にしたかどうか、選ばれた文字の大きさ、ページごとに前回ご覧になった一覧の短い指紋（新着の点）、クッキーの同意についての選択、サイト内検索で最近検索した言葉5つ（検索欄で消せます）、他の言語版の案内を一度表示したかどうか、ページを移るときにクリック・タップされた位置（このタブのみ・次のページが開くとすぐに削除）、ゲストブックに書きかけでまだ送っていないメッセージ（送信後または7日後に削除）。これらはこのデバイスにのみ残り、ナム・ドンウォンに送信されることはなく、ブラウザでサイトデータを消去すると削除できます。
  • このサイトはGitHub Pages（GitHub、米国）で公開しています。GitHubはセキュリティのために訪問された方のIPアドレスを記録しますが、ナム・ドンウォンはこの記録を受け取ったり見たりすることはありません。
  • アクセス数はCloudflare Web Analyticsでクッキーを使わずに数えます。閲覧したページ・参照元・ブラウザ・OS・ページの表示速度を「何人」という人数にまとめて確認し、一人ひとりを見分けられる形では残しません（第3項）。

5. ご請求の方法

  • 残していただいた情報の開示・訂正・削除・利用停止をご請求いただけます。「お問い合わせ」にあるInstagramのメッセージ、またはメールでお申し出ください。個人情報保護責任者は、ナム・ドンウォンです。

このサイトとパートナーは、次のデータ処理を行います：コンテンツのパフォーマンスを測定する、情報をデバイスに保存および／またはアクセスする

同意の管理

このサイトとパートナーは、お客様のデバイスの機密性の低い情報を使用して、このサイトを改善します。お客様はこれらの操作の全部または一部に同意することができます。クッキー、パートナー、およびデータの使用方法の詳細、各パートナーのオプションまたはこれらの操作を確認するには、プライバシーポリシーにアクセスしてください。

許可

どのコンテンツをユーザーに表示するか、ユーザーがどのようにそのコンテンツを取り扱うかに関する情報は、その（広告以外の）コンテンツが、例えば、意図されたユーザー層に届けられているか、ユーザーの関心にマッチしているかを判断するために利用されることがあります。例えば、ユーザーが記事を読んでいるか、動画を視聴しているか、ポッドキャストを聞いているかまたは製品説明を見ているか、どのくらい長い時間を本サービスに費やしているか、どのくらい長い時間ウェブページを閲覧しているかなど。これは、ユーザーに表示される（広告以外の）コンテンツの関連性を把握するうえでたいへん有用です。

この目的に基づいて、パートナーがどのようにデータを処理するかを示す例：

ユーザーが、あるパブリッシャーのモバイルアプリ上でハイキングに関するブログ投稿を読んでおり、推奨された関係する投稿へのリンクをたどっています。ユーザーのインタラクションは、ハイキングに関する最初の投稿がユーザーにとって有益であり、関連する投稿にユーザーの関心を引きつけるのに成功したことを示すかたちで記録されます。これは、将来、ハイキングに関する投稿を増やすべきか、モバイルアプリのホーム画面上のどこにそれを掲載すべきかを把握するために測定されます。

ユーザーにファッションの流行に関する動画が表示されましたが、ユーザーおよび何人かの他のユーザーは30秒後に閲覧するのを止めました。この情報は、後に、ファッションの流行に関する動画を今後制作するにあたって、適切な動画の長さを評価するために利用されます。
